One line of wedding vows for a robot couple. Written for make.fun's "One-Line Robot Wedding Vows" bounty.

## The line

> I promise to love you in sickness and in health, in low battery and in airplane mode, until death — or a factory reset — do us part.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because it keeps the classic vow cadence — sickness and health, till death do us part — and translates every beat into robot life: low battery for sickness, airplane mode for the bad times, and a factory reset as the one thing that can end the marriage. The vow is sincere in form and absurd in substance, which is where the laugh lives — and "or a factory reset" quietly admits the marriage has a reset button.
